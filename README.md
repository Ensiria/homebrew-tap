# Ensiria Homebrew tap

Casks for apps by [Ensiria](https://ensiria.eu).

## NowWave

Free, native macOS mini player for TIDAL, Spotify and Apple Music. https://nowwave.app

```bash
brew install --cask ensiria/tap/nowwave
```

Updates: `brew upgrade --cask nowwave`. Removal: `brew uninstall --cask nowwave` (add `--zap` to delete settings).
